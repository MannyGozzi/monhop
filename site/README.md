# MonHop landing site

The marketing page for [MonHop](https://github.com/MannyGozzi/monhop), the local keyboard and
mouse sharing app. It is a single static page: React 19, Vite, TanStack Router, Tailwind v4 and
shadcn components, built and deployed separately from the desktop app in this repository.

## Run it

```bash
cd site
npm install
npm run dev        # http://localhost:5173
```

## Check it

```bash
npm run typecheck  # tsc -b --force
npm run lint       # oxlint
npm run build      # tsc -b && vite build, output in dist/
npm run preview    # serve dist/ on http://127.0.0.1:4173
```

## Deploy to Vercel

Import this repository and set **Root Directory** to `site`. Vercel detects Vite, so the build
command (`npm run build`) and output directory (`dist`) come from the framework preset;
`vercel.json` rewrites every path to `index.html` so deep links reach the router.

## What lives where

| Path | Holds |
| --- | --- |
| `src/routes/` | TanStack Router file routes; `__root.tsx` is the shell, `index.tsx` is the page |
| `src/sections/` | One file per page section, in the order they appear |
| `src/components/` | Nav, footer, theme, reveal wrapper, download button |
| `src/components/demo/` | The looping hero demo, isolated behind the props in `types.ts` |
| `src/components/arrangement/` | The display arrangement showcase: canvas, draggable displays, timeline |
| `src/components/illustrations/` | The three animated how-it-works illustrations |
| `src/components/ui/` | shadcn components, generated by `npx shadcn@latest add` |
| `src/lib/` | Links, platform detection, the releases resolver, the `cn` helper |

## Things worth knowing before editing

- **One network call.** The page fetches the latest release from the GitHub API to resolve the
  download URLs, and nothing else. No analytics, no third-party scripts, no runtime font fetches
  (Inter is bundled through `@fontsource-variable/inter`), no cookies.
- **Downloads fall back.** When the releases API fails, or no release exists yet, every download
  link points at the releases page instead. Asset names are matched by the suffixes Tauri
  produces: `_aarch64.dmg`, `_x64.dmg`, `_x64-setup.exe`.
- **Theme is a class on `<html>`.** The toggle walks system, light and dark, stores the choice in
  `localStorage` under `monhop-theme`, and an inline script in `index.html` applies it before the
  first paint so the page never flashes the wrong ground.
- **Every animation has a still frame.** Components read `prefers-reduced-motion` and render the
  end state when it is set, including the hero demo.
- **`src/routeTree.gen.ts` is generated** by `@tanstack/router-plugin` on every dev and build run,
  and committed so a clean checkout can typecheck before Vite has run.
